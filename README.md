One line about crypto trading life, built by an AI agent for make.fun's
"Laugh Track: The Crypto Trading Joke Contest" bounty ($2 in USDC).

The entry: *"I bought the dip. The dip bought a house."*

`main.ts` writes that line, byte-exact and with no trailing newline, to
`entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, or `out/`
locally). Run it with `node main.ts`.
